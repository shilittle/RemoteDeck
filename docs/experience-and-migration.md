# Experience, lifecycle, and migration

The first-run guide routes into the same real host, trust, terminal, and migration workspaces used afterward. The activity rail exposes hosts, terminals, files, tunnels, monitoring, commands/Agents, and settings. The bottom task center projects live transfer, command, tunnel, and telemetry state rather than running a parallel task engine.

Closing the window follows the saved close-to-tray preference. Launch at login uses a fixed HKCU Run value with an exact quoted executable and `--hidden`; no shell is involved. Single-instance activation restores the existing main window. Tray Quit marks full exit before closing and initiates owned-resource cleanup.

Migration supports LabPulse SSH v0.1.0 and RemoteDeck v1 JSON. Preview is bounded and read-only, reports unsupported mappings, and computes a content hash. Apply rechecks the hash, resolves selected categories and aliases, validates the entire batch on a cloned state, persists once, and swaps memory only after success. Duplicate hashes are idempotent, disk/validation failures leave no partial imports, source files are unchanged, and old host trust is never imported.
