# RemoteDeck v2.1.1

修复本机 SSH 已能连接、RemoteDeck 却要求重复核验指纹的问题。
导入配置后可直接使用已有私钥连接，不必重新扫描、生成或部署密钥。

- 自动复用当前用户 `.ssh/known_hosts` 中对应地址和端口的已有记录，支持哈希记录和非默认端口。
- 服务启动时补齐旧版已导入主机的信任；保存和重新导入也会读取新增的本机记录，无需删除重建主机。
- 本机没有既有信任、服务器密钥变化、记录被撤销时仍保留严格检查；不修改全局 SSH 文件，不自动覆盖 RemoteDeck 已保存的指纹。
- 保存和导入返回可追踪任务，刷新或重复请求不会重复创建主机。
- 页面区分已有信任、尚未信任和读取失败，补充中文连接提示，防止未保存的表单误用旧连接资料。
- 延续后台进程隐藏启动，服务和 OpenSSH 子进程不弹出 cmd 窗口。

下载 `RemoteDeck-2.1.1-win-x64-setup.exe`，先在设置中停止旧服务，再安装。
安装包为 Windows 10/11 x64 当前用户版本，未签名，不包含浏览器运行时。
主机、私钥路径和 v2 用户数据继续保留。

自动复用限于标准用户 `known_hosts`；自定义 `UserKnownHostsFile`、`HostKeyAlias`、证书、通配符配置和递归 Include 不在本次新增支持范围。

验证：前端 49 项测试、Rust 213 项常规测试、5 项真实 OpenSSH 集成测试、4 项真实浏览器流程，以及格式、类型、Clippy 和 NSIS 安装/停止/卸载检查。
浏览器新增流程验证了哈希信任文件在服务启动后创建，导入后直接连接并恢复真实 ConPTY，且没有再次发送扫描或接受请求。
第三方 Agent 账户、完整 GPU/btop 环境和传输提升失败注入仍需外部验收，不计入本次通过项目。
