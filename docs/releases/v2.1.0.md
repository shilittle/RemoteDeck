# RemoteDeck v2.1.0

RemoteDeck 改为 Windows 本机后台服务与简单 WebUI，启动后打开默认浏览器。
移除 Tauri 和 WebView2，关闭页面后 SSH 终端、文件传输、命令和隧道继续运行。

## 主要变化

- 页面收敛为“主机、工作区、任务、设置”，保留主机信任与密钥、ProxyJump、SFTP、命令复核、Agent、监控和隧道操作。
- 终端支持刷新恢复、近期输出回放、断线重新附着及多页面独占接管，修复回放触发多余输入与退出清理误报。
- SSH 探测、遥测、命令、密钥工具等后台进程统一禁止创建控制台窗口；debug 和 release 主程序均使用 Windows GUI subsystem，修复反复弹出 cmd 窗口的问题。
- 修复带空格路径的安装参数及 NSIS 卸载等待竞态，安装验收完成后恢复原有安装登记。
- 承接依赖安全更新与 CI 检查，保留 v2 配置、备份、专属 `known_hosts` 和旧版选择性迁移。

## 安装

下载 `RemoteDeck-2.1.0-win-x64-setup.exe`，先退出旧版本，再运行当前用户范围安装包。
需要 Windows 10/11 x64、Windows OpenSSH Client 和默认浏览器。安装包不包含浏览器运行时或生产 Node.js。
用户数据继续位于 `%APPDATA%\io.github.shilittle.remotedeck`，卸载保留这些数据。

程序尚未签名。请使用同一 Release 中的 `SHA256SUMS.txt` 或 `release-manifest.json` 核对下载文件。

## 验证范围

本机发布检查覆盖前端 47 项、Rust 204 项常规测试、严格 Clippy、真实 OpenSSH 5 项、真实浏览器 3 项，以及隔离安装、浏览器认证、停止清理和卸载。
禁止弹窗修复后的两段 Windows 监听合计约 13 分钟，记录到 0 次控制台窗口显示事件。

真实第三方 Agent 账户登录、完整 GPU/btop 矩阵、干净 Windows 虚拟机人工升级和传输提升失败注入等外部验收尚未完成；详情见仓库中的 `docs/refactor-validation.md` 与 `docs/windowless-processes.md`。
