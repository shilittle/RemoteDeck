# RemoteDeck 用户指南

## 安装与启动

RemoteDeck 支持 Windows 10/11 x64。安装 Windows OpenSSH Client，并确认远端 Linux 主机运行 OpenSSH Server。运行安装包后，RemoteDeck 在当前用户后台启动本机服务并打开默认浏览器；服务只监听 `127.0.0.1`。再次启动会复用已运行的服务并打开其页面。

用户数据保存在 `%APPDATA%\io.github.shilittle.remotedeck`。卸载只移除安装目录、快捷方式、卸载记录和 RemoteDeck 登录启动项，保留主机、信任和迁移数据。若要彻底清除数据，请先导出需要的配置，再由当前用户手动删除该目录。

## 第一次连接

1. 在“主机”中添加别名、地址、端口、用户和默认工作目录；也可以导入 OpenSSH config 中的明确主机。
2. 选择“扫描指纹”，通过服务器控制台、管理员或其他独立可信渠道核对显示的 SHA-256 指纹。
3. 只接受完全匹配的指纹。之后出现主机密钥变化时，连接会被拒绝；确认服务器轮换后先删除旧信任，再重新扫描并核验。
4. 打开“工作区 → 终端”，在真实 SSH/ConPTY 会话中输入密码、键盘交互回答或私钥口令。RemoteDeck 不保存这些内容。

后台 SFTP、隧道、监控、命令和 Agent 探测需要可用的私钥或 ssh-agent。密码认证主机应先在终端完成认证并部署公钥。

## 工作区

“工作区”始终显示当前主机，默认进入终端。浏览器刷新或重新打开页面会从服务端恢复会话和任务。

- **终端**：打开、切换、重命名、搜索、复制粘贴、调整尺寸、中文输入和重连。每个会话由服务端持有，浏览器关闭不会停止。重新附着会回放最近最多 1 MiB 输出；发生截断时页面会明确提示。
- **文件**：浏览目录、返回上级、新建、重命名、删除，上传下载文件或目录。冲突策略包括询问、覆盖、跳过和自动改名。覆盖先写入 RemoteDeck 临时文件并保留备份，失败时回滚；任务中心显示进度、取消和重试。
- **命令与 Agent**：命令执行前按最终内容重新计算 L0/L1/L2 风险。危险命令需要相应确认。Codex、Claude、Gemini、OpenCode 支持探测、安装/更新、登录、启动和 tmux 恢复，权限和账号状态仍由官方工具管理。
- **监控与隧道**：查看 CPU、内存、网络、磁盘、GPU、进程、btop 和历史；启动 LocalForward 或 RemoteForward，查看健康、重连和有界日志。缺少远端工具会显示降级状态。

## 主机、ProxyJump 与密钥

主机可搜索、分组和导入。ProxyJump 只能选择已保存且可直接连接的主机；必须先核验跳板指纹，再通过跳板扫描并核验目标指纹。嵌套跳板、任意 ProxyCommand、通配符和递归 Include 不会被导入。

密钥页面可发现本机私钥、生成 Ed25519 密钥，并在用户确认后将公钥部署到已核验主机。RemoteDeck 使用独立 `known_hosts`，不修改用户全局文件。

## 任务、设置与生命周期

“任务”汇总跨主机的传输、命令、监控和隧道。长操作立即返回任务 ID；刷新不会重复执行。可查看详情、取消、重试并返回对应工作区。

“设置”用于终端偏好、监控保留、默认工作目录、登录后后台启动、迁移、诊断和停止服务。停止服务会先拒绝新任务，再在有界时间内清理当前实例创建的子进程和远程 watchdog，不会结束任意进程。

诊断包只含脱敏状态、能力和可信指纹，不含密码、私钥、令牌、终端内容或远程命令输出。服务通过 SSE 推送有序状态；浏览器重连发现事件缺口时会自动请求完整快照。

## 快捷键

- `Ctrl+1`：主机
- `Ctrl+2`：终端
- `Ctrl+3`：文件
- `Ctrl+4`：命令与 Agent
- `Ctrl+5`：监控与隧道
- `Ctrl+6`：任务
- `Ctrl+,`：设置
- `Ctrl+Shift+T`：新建终端
